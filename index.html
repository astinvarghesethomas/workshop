FAQ

Frequently Asked Questions

Find answers to common questions about using and customizing this website.

Do I need Node.js or any build tools to run this website? ▾

No build tools or servers are required! This site is built with pure standard HTML5, CSS3, and vanilla JavaScript. Simply open index.html in any web browser and it will work instantly.

How can I customize the color scheme and fonts? ▾

All colors, fonts, spacing, and shadows are defined in the :root block of style.css. You can easily adjust --primary, --bg-color, and typography in one central location.

Is this website accessible and responsive across mobile devices? ▾

Yes. The layout is built with fluid CSS Grid and Flexbox with dedicated breakpoints for smartphones, tablets, and desktops. It adheres to accessibility guidelines with proper contrast ratios and semantic tags.

Can I host this on GitHub Pages, Vercel, or Netlify? ▾

Yes, absolutely. Because there are no backend dependencies, it can be deployed to any static host (GitHub Pages, Cloudflare Pages, Netlify, Vercel, or AWS S3) with zero configuration.
